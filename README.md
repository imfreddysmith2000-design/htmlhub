# htmlhub

## msk_console.html — msk.py

Python-подобная консоль московского времени для программистов. Один HTML-файл без зависимостей и сборки: откройте его в браузере.

- **REPL в стиле Python**: `>>>`, `int` произвольной длины, f-строки, срезы, генераторы списков, `lambda`, однострочные `def`, распаковка, трейсбеки как в CPython и подсказки `Did you mean`.
- **Удобный ввод**: Tab дополняет имена, атрибуты и часовые пояса; → принимает подсказку из истории (как в fish); ↑↓ листают историю по введённому префиксу; Ctrl+R ищет по истории; над полем ввода видна сигнатура функции.
- **Время**: `now('tokyo')`, `dt('tomorrow 9:00')`, `until('new year')`, `epoch(1700000000123)`, `world()`, `overlap('sf', 'berlin')` (общее окно для созвона), `cron('*/15 9-18 * * 1-5')`, `cal()`, `tz('ny')`.
- **Для разработчиков**: `decode()` достаёт время из JWT, UUID v1/v6/v7, ULID, ObjectId, KSUID, snowflake и unix-меток; есть `jwt()`, `sha256()`, `md5()`, `b64()`, `uuid7()`, `ulid()`, `pw()`, `chmod()`, `http()` и модули `time`, `datetime`, `math`, `random`, `json`, `re`, `hashlib`, `base64`, `uuid`, `secrets`, `urllib`.
- **Задачи**: `timer('25m')`, `every('45m', 'размяться')`, `alarm('10:00', 'стендап', days='будни')`, `pomodoro()`, секундомер `sw`. Задачи хранятся в localStorage и переживают перезагрузку страницы.
- **Небо и точность**: `sun()`, `moon()`, `season()`, `weather()` (Open-Meteo); `sync()` сверяет часы с HTTPS-серверами точного времени.
- **Автоматизация**: `%startup world(); sun()` запускает команды при открытии, `cfg.*` хранит настройки, `#world` в URL сразу выполняет `world()`, клик по значению в таблице копирует его.

Справка по всем командам: `help()`. Справка по одной функции: `timer?`.
